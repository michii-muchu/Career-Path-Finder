# Career Path Finder 🎯
An AI-powered career guidance web app designed for students who are confused about choosing the right career path.

## Features
- 🤖 AI-generated dynamic assessment questions
- 🎯 Personalized career recommendations based on your answers
- 🗺️ Step-by-step roadmap — entrance exam to first job
- 🏫 AI-recommended colleges with course & fee details
- 🔍 Search & filter across 50+ career options

## Tech Stack
- Frontend: HTML, CSS, Vanilla JavaScript
- Backend: Node.js, Express.js
- AI: Groq API (LLaMA 3.3 70B)
- Database: JSON
